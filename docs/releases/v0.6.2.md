# Hum 0.6.2

Hum 0.6.2 adds native composition for large version 3 configurations while
preserving the existing machine-local override model.

## Highlights

- Split a committed `hum.yaml` into an explicit, ordered `imports` list.
- Resolve imported paths relative to the main configuration directory.
- Apply `hum.local.yaml` after all committed fragments, so local values can
  override or complete imported definitions before final validation.
- Attribute schema and semantic validation errors to the fragment that
  introduced the affected field.
- Reject duplicate named definitions across the main file and imports.
- Reject absolute paths, parent traversal, self-imports, canonical duplicate
  paths, and symlink targets that resolve outside the main configuration
  directory.

## Upgrade notes

Imports require `version: 3`. Imported fragments must not declare `version`,
`project`, or nested `imports`; those fields remain owned by the main
`hum.yaml`. Existing configurations without `imports` continue to load as
before.
